The scenarios

Two workloads carry the whole workshop

Every module applies to a concrete system so decisions have consequences you can measure.

Greenfield · retail

Contoso order platform

  • Public order API, private internal catalog, a Service Bus worker, and a scheduled reconciliation job
  • PostgreSQL, Key Vault, and an approved Azure Container Registry
  • 100 req/s average, 1,500 req/s peak
  • 99.95% availability · RTO 30 min · RPO 5 min
Brownfield · migration

Fabrikam modernization

  • A .NET web app and a Windows service running on VMs today
  • Local session state and file uploads, SQL polling, config-stored connection strings
  • Decide what ports to ACA, what is retained, and what needs another service
  • Sequence a strangler migration with gates and a time-bounded rollback
